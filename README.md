# Mon3tr 桌宠 · 常驻托盘版

双击 Mon3tr.exe 启动。人物、动画和三段语音已内置，Windows 10 / 11 无需额外安装运行工具。

- 保留最近一次放大 10% 后的人物大小。右键可以放大、缩小，或“恢复默认大小”。
- 点击人物：播放新的约 60 FPS 互动动画，按“部署1”45%、“问候”45%、“戳一下”10% 的概率随机播放一段语音，并重新读取额度。连续点击会重播互动，前一段语音停止，避免叠加。
- 聊天框已缩小，删除底部两行说明和刷新按钮。出现时放大展开，显示 5 秒后缩小收起。重复点击重新计时；网络回复较晚不会重新弹出聊天框。
- 按住左键拖动。移动范围按人物实际轮廓计算，透明画布可以越过边界，不会再提前弹回。
- 拖到当前屏幕可用区域的任意边缘后松手，人物隐藏，边缘留下绿色小标签。鼠标移上或点击标签即可恢复。若隐藏时鼠标正好停在标签上，先移开再移入，避免刚隐藏就弹回。
- 托盘图标已换成你提供的 Mon3tr 头像，棋盘格背景已去除。程序文件图标也使用同一头像。
- 关闭操作、Alt+F4 和最小化都会收起到托盘，程序继续运行；右键菜单不再提供“退出”。也可主动选择“收起到托盘”。
- 在 Windows 右下角托盘（可能在“^”隐藏图标中）双击头像，即可恢复；右键头像可以选择“显示桌宠”或“找回到桌面”。图标位于展开区还是隐藏区由 Windows 托盘设置决定。
- Windows 关机、注销会正常结束程序，不会阻止系统退出。当前没有额外配置开机启动。

聊天框默认左上角，左侧空间不足时切到右侧，并避开屏幕边界。

## 北京时间与问候

聊天框增加北京时间，显示到秒，可见期间每秒更新。使用电脑系统时钟换算到 UTC+8，不受 Windows 当前时区选择影响。问候语也按北京时间自动切换：

- 05:00（含）—12:00（不含）：早上好
- 12:00（含）—18:00（不含）：下午好
- 18:00（含）—次日05:00（不含）：晚上好

跨过时段边界时，可见聊天框中的问候会随时间更新。5 秒自动收起仍然保留。

## 额度

每次点击都会发起新的查询，没有上一版的 15 秒缓存限制。复用后台账号连接，查询不会在动画播放线程中执行。等待期间显示上次结果并标记“正在更新”；失败时明确标记旧数据。

数据仍是已登录 ChatGPT 账号的 Codex 额度，并非 ChatGPT 所有功能的总额度。根据你的要求，范围说明已移出聊天框，仅保留在此处。

请保留已安装并登录的 Codex，保持网络可用。其他安装方式可用 MON3TR_CODEX_PATH 指定 codex.exe。程序不保存账号密码或登录令牌，不发送模型聊天请求，不兑换重置券。

接口文档：https://learn.chatgpt.com/docs/app-server

## 动画优化

新上传的 AV1 动画共有 132 帧，保留全部源帧及原始时间间隔。素材启动时解压到内存，播放时复用同一个绘图缓冲区，无需逐帧解码或访问磁盘。跟随屏幕刷新顺序呈现，不再按经过时间直接跳帧。

系统忙碌或低刷新率屏幕下可能稍微延长动作时间，以优先完整播放；无法承诺 Windows 在任何负载下都完全无卡顿。

新视频虽然标记 alpha_mode，但没有实际透明数据，因此已去除与外部连通的黑色背景，并保留封闭区域内的深色细节。待机仍使用上一版原版站姿，缩小后显示。

## 文件

程序安装在 E:\Mon3tr，双击 E:\Mon3tr\Mon3tr.exe 启动。Mon3tr.exe 已内置所需素材，可单独运行。settings.json 记录位置、大小、置顶和隐藏状态，删除可恢复默认值。已迁移原来的设置。图标的透明 PNG 和多尺寸 ICO 也保存在安装目录。

开发源工程仍保留在项目工作区，入口为 src/PetV2.cs，额度连接在 src/UsageConnection.cs，构建使用 build.ps1。tools/prepare_v2.py 重建视频缓存。qa/v2-tests.txt、qa/v3-interaction.txt 保存本机检查结果。交付压缩包不含账号快照或个人设置。
